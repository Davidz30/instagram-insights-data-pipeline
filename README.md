# Instagram Insights Data Pipeline

Projeto demonstrativo de engenharia de dados: Meta Graph API → Python → SQL Server → Power BI.

> **Status:** repositório privado em preparação. Não usar em produção sem revisar segurança, dependências e permissões.

Os códigos públicos devem utilizar somente configurações externas, nunca tokens, senhas, nomes de usuários, IDs de contas ou endereços de infraestrutura reais.

## Política de publicação

- Não versionar `.env`, credenciais, logs ou dados extraídos.
- Utilizar exemplos exclusivamente fictícios.
- Revisar os arquivos antes de tornar o repositório público.
- Executar auditoria de dependências e análise estática.
- Revogar credenciais expostas anteriormente.

A versão completa será adicionada após a conferência dos arquivos sanitizados.
